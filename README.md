# Инструкция: как вести сайт

## Как это работает

Сайт собирается автоматически из файлов, которые лежат в Obsidian.
Публикация запускается вручную кнопкой **Sync** в Obsidian.
После нажатия Sync изменения через 1–2 минуты появляются на сайте.

Разделение ответственности:
- **Контент** — полностью на вашей стороне (тексты, изображения, структура проектов).
- **Деплой и инфраструктура** — на стороне разработчика.
- **Дизайн** — правки собираются списком и передаются разработчику (см. конец документа).

## Структура хранилища

```
info/
  info.md
  avatar.jpeg
portfolio/
  project-01/
    project.md
    foto1.jpg
    foto2.jpg
  project-02/
    project.md
```

- `info/` — данные о вас (имя, описание, контакты, список проектов).
- `portfolio/` — папки проектов. Одна папка = один проект.

---

## Файл info.md

Это главный файл с информацией о вас. Состоит из блоков.
Каждый блок начинается с ключевого слова на отдельной строке.

Пример:

```
photo
![аватар](avatar.jpeg)

name
Поля Шустова

about
Текстовая художница

contacts
[тгк](https://t.me/pshtto)
[инст](https://www.instagram.com/anilishus/)

portfolio
project-01
project-02
project-03
```

### Что означают блоки

**photo** — изображение для аватара. Одна картинка. Файл кладётся рядом с `info.md`.

**name** — имя или название, которое видно на главной странице.

**about** — короткое описание (одна строка или небольшой абзац).

**contacts** — список ссылок. Каждая ссылка с новой строки в формате `[текст](ссылка)`.

**portfolio** — список папок проектов. Каждое имя с новой строки.
Порядок строк = порядок проектов на сайте. Верхняя строка — первый проект.
Имена должны точно совпадать с названиями папок внутри `portfolio/`.

Чтобы изменить имя, описание или контакты — правьте прямо в блоках.
Обновление появляется на всём сайте (главная страница, шапка, футер).

---

## Как добавить новый проект

1. В папке `portfolio/` создайте новую папку.
   Правила имени:
   - только латиница;
   - без пробелов (разделяйте дефисом);
   - без кириллицы.
   Пример: `project-04`, `text-about-me`, `diary-2026`.

2. Внутри папки создайте файл `project.md`.

3. В `info.md` в блоке `portfolio` добавьте имя этой папки на отдельной строке.
   Порядок строк определяет порядок проектов на сайте.

4. Положите в папку проекта изображения, которые будут использоваться в тексте.
   Изображения должны находиться в той же папке, что и `project.md`.

5. Нажмите **Sync** в Obsidian.

## Как работает контент в project.md

### Заголовок первого уровня

Заголовок первого уровня (`# Заголовок`) всегда отображается один на отдельной странице — как титул проекта.

Остальные заголовки (`##`, `###`, `####` и далее) идут в общем потоке текста.

### Изображения

Всё зависит от того, где стоит изображение.

**Изображение перед заголовком первого уровня** — становится обложкой проекта.
Занимает всю страницу, поверх — название проекта.
Используется один раз, в самом начале файла.

```
![фото](01.jpg)

# Название проекта

Текст проекта.
```

**Изображение сразу после заголовка первого уровня** — отображается одиночно, по центру страницы, с отступами.

**Два изображения подряд** — идут двумя картинками в колонку на отдельной странице, с отступами и скруглениями.

**От трёх до пяти изображений подряд** — идут в общем потоке текста, сеткой.

**Шесть и больше изображений подряд** — автоматически переносятся на отдельные страницы-плитки. На каждой странице — 24 изображения (3 колонки × 8 строк).

**Одиночное изображение, отделённое пустой строкой** — становится большой картинкой на всю страницу.
Если до него уже было изображение-одиночка, второе идёт как обложка на всю страницу.

Как вставить изображение в Obsidian:
- перетащить файл мышью прямо в текст — появится `![[файл.jpg]]`, но лучше использовать явный формат `![подпись](файл.jpg)`;
- либо вручную написать `![подпись](файл.jpg)` и положить файл в ту же папку.

Изображения должны лежать **внутри папки проекта**. Внешние ссылки работают, но не рекомендуются.

### Списки, чек-листы, буллеты

```
- пункт
- пункт

1. первый
2. второй

- [ ] задача
- [x] выполнено
```

**Список из 6 пунктов и больше** автоматически переносится на отдельную страницу.
Список из 5 пунктов и меньше идёт в общем потоке текста.

Если перед списком (6+) в тексте нет пустой строки — предыдущий абзац или заголовок захватывается вместе с ним на эту страницу.

### Цитаты

```
> важная мысль
```

Цитата всегда отображается отдельной страницей, по центру.

### Разделитель

```
---
```

Обычная горизонтальная линия.

### Разделитель-цветок

Оставьте **две пустые строки** между блоками текста — в этом месте появится случайный цветок по центру.
Одна пустая строка и меньше — цветок не появляется.

### Код

Блок кода используется для одиночных текстов, например стихотворений.
Текст одиночно отображается на отдельной странице, по центру по вертикали, с отступами, выравнивание по левому краю.

Доступны варианты:

Одинарные кавычки с двух сторон:
```
`текст стихотворения`
```

Двойные кавычки:
```
``текст``
```

Тройные кавычки:
```
```
текст стихотворения
в несколько строк
```
```

Работают все три варианта. Многострочный текст внутри кавычек превращается в один блок на отдельной странице.

Кавычки не влияют на появление цветков-разделителей между блоками — можно спокойно ставить два блока подряд.

## Навигация

**Клик по названию проекта** в шапке страницы — возвращает на главную.

**Клик по названию в футере** внутри проекта — переходит на первую страницу этого проекта.

Стрелки клавиатуры, свайпы и клики по краям перелистывают страницы.

Ссылка на конкретную страницу формируется автоматически и обновляется в адресной строке браузера.

---

## Порядок работы

1. Открыть Obsidian.
2. Внести правки в `info.md` или в один из файлов `project.md`.
3. Проверить, что имя папки совпадает с именем в блоке `portfolio` в `info.md`.
4. Проверить, что все используемые изображения лежат в папке проекта.
5. Нажать **Sync** в Obsidian.
6. Подождать 1–2 минуты.
7. Обновить сайт в браузере (иногда нужно жёсткое обновление: `Ctrl+Shift+R` / `Cmd+Shift+R`).

---

## Чего не делать

- Не переименовывать папки проектов после публикации — старая ссылка перестанет работать.
- Не удалять файл `project.md` из папки проекта — проект пропадёт.
- Не использовать кириллицу и пробелы в именах папок внутри `portfolio/`.
- Не менять имя папки в `portfolio/`, не обновив блок `portfolio` в `info.md`.

---

## Правки в дизайн

Если нужно что-то поменять в оформлении — соберите список задач и передайте разработчику.
В список стоит включать:
- что именно не устраивает;
- на какой странице это видно;
- как хочется, чтобы выглядело (по возможности).

Все правки в интерфейсе, структуре и логике вносит разработчик.
Все правки в тексте, изображениях и проектах — на стороне пользователя.

---

## Если что-то не работает

Проверьте по порядку:

1. Имя папки в `portfolio/` совпадает с именем в блоке `portfolio` в `info.md`.
2. Файл в папке проекта называется `project.md`.
3. Все изображения лежат в папке проекта и не переименованы.
4. Sync был нажат после последних изменений.
5. Обновите страницу в браузере жёстко (`Ctrl+Shift+R` / `Cmd+Shift+R`).

Если после этого что-то не отображается — передайте разработчику описание проблемы.
